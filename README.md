# Skaiste Savitri Portfolio

A Next.js portfolio site for Skaiste Savitri, built with React, TypeScript, Tailwind CSS utilities, and Framer Motion.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs the Next.js lint check.

## Project Structure

- `src/app` contains routes, metadata, and app-level styles.
- `src/components` contains reusable interface pieces.
- `src/data` contains portfolio content used across pages.
- `src/hooks` contains reusable React hooks.
- `public` contains static files such as project images and the CV.
